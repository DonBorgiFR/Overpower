# Scripture Translator Skill

This skill allows the agent to navigate the "Base de Escrituras Budistas Zen de Alto Nivel" and translate its concepts into contemporary Western language.

## Instructions

When asked to translate or explain a scripture from the base:

1. **Identify the Level**:
    - Level 1: Sutras Mahayana (Heart, Diamond, Lanka, Vimalakirti, Loto).
    - Level 2: Fundational Chan/Zen (Platform, Xinxin Ming, Sandokai, Hokkyo Zanmai, Fukanzazengi).
    - Level 3: Dogen Zenji (Shobogenzo, Bendowa).
    - Level 4: Koans (Hekiganroku, Mumonkan, Shoyoroku).
    - Level 5: Poetry/Liturgical (Zenrin Kushu).

2. **Retrieve Context**:
    - Locate the specific text in the `Base de Escrituras Budistas Zen de Alto Nivel.md`.
    - Check the "Relevancia zen" section provided in the base for that text.

3. **Apply Editorial Bridge**:
    - Use the `02_Glosario_Puente_Zen_Occidental_V0.md` (if available) to ensure terminology consistency.
    - Follow the "Regla de Traduccion de Terminos" from the Editorial Guide:
        - Termino original -> Traduccion funcional -> Uso practico -> Alerta.

4. **Draft the Translation**:
    - Avoid "autoayuda superficial" (shallow self-help).
    - Maintain "fidelidad doctrinal" (doctrinal fidelity).
    - Use contemporary metaphors (e.g., "nada existe por si solo" for Emptiness).

5. **Structure the Output**:
    - Follow the "Estructura Minima de Cada Seccion" from the Editorial Guide:
        1. Idea nuclear.
        2. Marco doctrinal.
        3. Traduccion occidental.
        4. Aplicacion contemplativa.
        5. Alertas de interpretacion.

## Usage

Use this skill to:
- Generate new chapter content based on a specific scripture.
- Answer questions about the meaning of technical Zen terms.
- Cross-reference different scriptures.
